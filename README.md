This is my study project from a Python course at SPbPU :) The code is a bit clunky—I’d definitely write it better now, but after all, it’s almost 2 years old.

Features: music playback, selecting a song from the playlist, displaying the current track's title and cover art, volume control, displaying the current time and total track duration, seeking with a slider, play, pause, and stop buttons, skipping to the next and previous tracks, and shuffling/random song selection.

Technologies used: Python, PyQt5 (Qt Widgets, Qt Multimedia), Qt Designer, QMediaPlayer, QMediaContent, QSlider, QLabel, QTimer.
